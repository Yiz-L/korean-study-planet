## 📖 简介

**韩语小星球** 是一个面向零基础追星族的一站式韩语学习网站。打开即用，无需注册、无需登录。

### 🎯 核心理念

| 你的情况 | 解决方案 |
|---------|---------|
| 🎤 喜欢 idol，想看物料听懂综艺 | 每日任务直接链接 YouTube 英语教学视频 |
| 🌍 选了《地球游戏厅》当学习资料 | 每课安排中字观看 + 找关键词任务 |
| 🌸 喜欢 IU | 内置 IU 歌词卡 + 直接链接 YouTube MV |
| 🇬🇧 英语有一定基础 | 全部教学资源为英语讲解，学韩语同时练英语 |
| 📚 会考试但应用弱 | 听说读写四维任务全覆盖，不做哑巴韩语 |

## 🗺️ 学习路径

整个学习计划共 **30 天**，分 4 个阶段：

```
🌱 字母爆破期    Day 1-3        한글 40音 → 基础拼读
🌱 语法入门期    Day 4-10       SOV语序 → 助词 → 动词 → 过去时 → 问候语
🌿 内容输入期    Day 11-20      TTMIK L2 → 词汇积累 → 真实内容输入
🌳 自主进阶期    Day 21-30+     TTMIK L2+ → 自主输出 → 流利度提升
```

### 每天的任务构成

| 任务类型 | 数量 | 资源形式 | 说明 |
|---------|------|---------|------|
| 📺 视频学习 | 1 条 | YouTube 英语教学视频 | Go! Billy Korean / TTMIK / Miss Vicky |
| 🌸 IU 歌曲 | 1 条 | YouTube MV → 歌词学习 | 每天一首 IU 金曲 |
| 📝 词汇练习 | 1 条 | Anki 词包推荐 | 推荐词包：Korean Grammar Sentences by Evita |
| 🎬 地球游戏厅 | 1 条 | B站中字链接 | 从"看中字"到"找关键词"逐步深入 |

## 🔧 部署指南

### GitHub Pages（推荐）

1. Fork / Clone 本仓库
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 **main / master**，目录选 **/ (root)**
5. 点击 Save，等待 1-2 分钟即可通过 `https://<用户名>.github.io/korean-study-planet` 访问

### 自定义域名

1. 在仓库根目录创建 `CNAME` 文件，写入你的域名（如 `korean.yourdomain.com`）
2. 在 DNS 管理处添加 CNAME 记录指向 `<用户名>.github.io`
3. 在 GitHub Pages 设置中输入自定义域名

### 本地部署

项目是纯静态 HTML，无构建步骤、无依赖。可直接上传到任意静态托管服务（Vercel / Netlify / 阿里云 OSS 等）。

## 📌 注意事项

- 学习进度保存在浏览器 **localStorage** 中，**清除浏览器缓存会丢失所有数据**
- 建议定期截图打卡记录，或使用 Chrome 同步功能备份
- 每日任务设计为 **约 50-60 分钟**，可根据个人时间调整
- 地球游戏厅从 **Day 1** 开始就作为娱乐调味剂出现，不需要等学好了再看
